# Vue with weather

Weather project made using OpenWeather API with Vue.js and Vite.

## Setup

Create a local env file and add your OpenWeather API key:

```env
VITE_OPENWEATHER_API_KEY=your_openweather_key
```

Use `.env.local` for local development. Do not commit real API keys; if a key was previously committed, rotate it in OpenWeather.

## Scripts

```sh
npm run dev
npm run optimize:images
npm run lint
npm run build
```
